# 6-Week Roadmap

## Week 1 — Discovery
- 10 user interviews
- Rank problems
- Competitor teardown
- Finalize ICP and success metrics

## Week 2 — Ingestion
- CSV upload
- Feedback schema
- Analysis pipeline
- Basic dashboard

## Week 3 — Evidence + prioritization
- Theme clustering
- Evidence drill-down
- Transparent score
- Filters

## Week 4 — AI evaluation
- Build 200-item labeled test set
- Measure classification/theme agreement
- Improve prompts/taxonomy
- Confidence + failure states

## Week 5 — Usability
- 5–8 PM usability tests
- Measure task completion + synthesis time
- Iterate UX

## Week 6 — Pilot
- 3–5 design partners
- Instrument analytics
- Collect retention/action metrics
- Write final PM case study
